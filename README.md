# centrifuge
Small compatibility-focused container for `centrifuge`.

## how to use
```bash
docker run --rm -v "$(pwd):/data" picotainers/centrifuge:latest --help
```

## Quick Usage

```bash
# Pull the image
docker pull docker.io/picotainers/centrifugeatest

# Run the tool
docker run --rm docker.io/picotainers/centrifugeatest centrifuge --help
```
